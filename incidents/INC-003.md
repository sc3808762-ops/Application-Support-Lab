# Incident Report – INC-002

Incident ID: INC-002

Incident Title: Application Response Time Increased

Severity: High (Provisional)

## Symptoms:
1. Login taking 15 seconds.
2. Dashboard taking 20 seconds.
3. HTTP 500 errors occurring during requests.

## Initial Findings:
- CPU Usage: 92%
- Memory Usage: 88%
- Database: Active
- Application: Running

## Investigation:
1. Checked application logs to identify errors and warnings.
2. Checked CPU usage using the `top` command.
3. Checked memory usage using the `free -h` command.
4. Checked disk space using the `df -h` command.
5. Checked whether the Java application process was running using `pgrep`.
6. Checked database connectivity because database connection timeouts were reported.
7. Found high CPU and memory usage, which could be contributing to slow application response times.
8. Collected error logs and system information for further investigation.

## Root Cause:
The exact root cause is currently unknown.

High CPU and memory usage are possible contributing factors. Further investigation is required to identify the actual cause.

## Resolution:
1. Collected application logs and system resource information.
2. Checked application and database status.
3. Shared the investigation findings with the next-level support team.
4. Recommended investigating high resource consumption and database connection timeouts.

Status: Pending further investigation.

## Prevention:
1. Monitor CPU and memory usage regularly.
2. Monitor application logs for errors and warnings.
3. Monitor database connectivity and response time.
4. Set up alerts for high CPU and memory usage.
5. Perform regular application health checks.
6. Investigate repeated HTTP 500 errors to prevent future incidents.
